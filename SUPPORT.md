# MASUM CHRONOS — Support

To report bugs, request features or seek installation help, open an issue:

https://github.com/gitwithmasum/Masum-Chronos/issues

Please include your OS, VS Code and CHRONOS versions, reproduction steps, and relevant non-sensitive error messages. **Never post your local sync pairing key, passwords, tokens or private tasks.**

For Windows troubleshooting: use the Command Palette → `CHRONOS: Open Focus Command Center`; if missing, reload VS Code and check the extension is enabled. For Chrome pairing, keep VS Code open and permit localhost access as required by your browser.

Chrome/PWA and VS Code do not share running timers, focus statistics or themes. The optional local bridge syncs To-Do Missions only on the same computer.
